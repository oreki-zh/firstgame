# firstgame — 异世界旅行与探索 RPG

一个以同行旅人、路线选择和共同经历为核心的单人电脑像素 RPG 构想。正式游戏名称待定。

玩家扮演从地球被放逐的旅行领队，在城市分配成员收集情报与资源，再规划路线，带领团队前往不同异世界国家旅行探索。战斗中主角通过卡牌影响局势，不直接参战；露营等生活事件中主角会亲自参与。成员的能力、性格、愿望和成长会改变可以选择的道路及沿途经历。

最新主线设定：旅行发生在一个原始而有魅力、接纳被放逐者并充满「狩奇者」的新星球。主角通过与自身专长相关的探索壮举，争取返回地球的资格；登山者／探测家的例子是收集 7 张奇观照片，狩猎人的候选目标是获得 5 个奇兽部位。选择主角时可了解主角与初始随从在地球的职业和被放逐原因，这些背景随狩猎、探险、拍照记录等主线类型配置。资格认定与回归方式仍待定。

旅途中，玩家会逐渐发现狩奇者建立的家园与城市、当地地貌和气候与地球十分相似，但有更少的人为开发痕迹，并能发现原本世界已经灭绝的动植物。居民会用在地球生活的经验介绍当地旅行注意事项。最终，玩家可以选择回地球或留在这片未知而美丽的世界；是否确为平行时空尚未确定。

> 当前阶段：设计访谈与需求整理。仓库目前仅包含文档，尚未实现可运行的游戏。

## 阅读约定

- **已确认**：用户明确表达的设定或需求；不代表已经实现，也不代表不能修改。
- **倾向／待确认**：用户提出了方案，但同时在征求意见，或仍有执行细节未定。
- **待定**：对话尚未给出答案；不自动填入默认规则。
- **助手建议**：讨论中的候选设计，尚未获得用户确认。
- **整理性概括**：把已有回答连接起来的文字表达，不新增游戏规则。
